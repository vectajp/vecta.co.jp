# 公開事例・削減効果メモ

作成日: 2026-03-11

## 目的

営業資料で `どれくらい効率化が見込めるか` を説明するための公開ベンチマーク整理。

## 数字の見方

公開事例の数字は、同じ意味ではない。営業資料では以下を混ぜない。

- `入電・問い合わせ件数の削減`
- `AIのみで完結した比率`
- `応答業務・工数の削減`
- `待ち時間やつながりやすさの改善`

## Grafferの公開事例

### 1. 北九州市 / 市民課 / マイナンバーカード関連

- 公開日: `2026-01-26`
- 公開内容:
  - 区役所市民課市民係へのマイナンバーカード関連電話のうち `約半分をAIで完結`
  - AIが質問内容を聞き取り、マイナンバー関連は自動回答、それ以外は担当課へ転送
  - `交付通知書到着後の手順` `持参物` `電子証明書の有効期限通知` などの定型質問で完結事例あり
- 営業資料での使いどころ:
  - `住民課`
  - `マイナンバーカード関連`
  - `定型質問と人転送のハイブリッド運用`
- 出典:
  - https://graffer.jp/govtech/articles/kitakyushu-ai-call

### 2. 吹田市 / 国民健康保険課

- 公開日: `2023-05-10`
- 公開内容:
  - 月 `6,000〜8,000件` の電話問い合わせ
  - `約45%` の受電を自動化
  - `月50時間以上` の業務削減
  - 音声案内で担当グループへ振り分け、取り次ぎ待ちやたらい回しを減らす運用
- 営業資料での使いどころ:
  - `代表電話や専門課の電話振り分け`
  - `IVR + AIによる一次対応の効果`
  - `月間削減時間の見せ方`
- 出典:
  - https://graffer.jp/govtech/articles/suita-kokuho

### 3. 小平市 / 市民課 / マイナンバーカード関連

- 公開日: `2025-03-31`
- 公開内容:
  - マイナンバーカード問い合わせ増加に伴う `電話がつながらない` 不満の解消を目的に導入
  - 定量削減率は公開されていないが、`つながりやすさ` と `満足度` の改善を訴求
- 営業資料での使いどころ:
  - `削減率がまだ出ていない案件でも、住民満足や到達性の改善で語れる`
  - `住民課・マイナンバー窓口との相性`
- 出典:
  - https://graffer.jp/govtech/articles/kodaira-ivr
  - https://graffer.jp/news/6358

### 4. 京都市 / 全区役所・支所代表電話

- 公開日: `2025-05-30`
- 公開内容:
  - 全11区の区役所と3支所の代表電話等に導入
  - `24時間365日` の自動音声と `SMS` を通じて情報提供
  - 実証実験を経て、本格導入
  - 定量削減率は公開されていないが、`市民利便性向上` と `職員負担軽減` を両立と説明
- 営業資料での使いどころ:
  - `全庁横断展開のイメージ`
  - `代表電話 + SMS連携`
- 出典:
  - https://graffer.jp/news/6613

## SwarrowCall向けの解釈

以下は上記の公開事例からの `推定` 。

- `住民課・マイナンバーカード関連`
  - 通知到着後の手順確認、持参物、暗証番号、電子証明書などは定型質問が多く、一次対応の自動化と相性が良い
- `代表電話・専門課`
  - 案内と振り分けだけでも、転送や取り次ぎの負荷を下げやすい
- `電話 + HP/LINE`
  - 電話だけでなくチャット導線も併用すると、入電抑制と応答時間短縮の両方を狙いやすい

## 営業資料で使いやすい表現

### 数字をぼかして使う場合

- `定型問い合わせや一次受付を中心に、対応工数の削減が見込めます`
- `まずは住民課や代表電話など、問い合わせが集中する業務でPoCを行い、削減率を実測します`
- `FAQ比率の高い窓口では、一次対応の自動化余地が大きいと考えられます`

### 数字を入れる場合

以下は公開事例を踏まえた `提案用レンジ` であり、SwarrowCallの実績値ではない。

- `対象業務で20〜30%程度の工数削減余地を検証`
- `定型比率の高い窓口では、一次対応の30〜50%程度に自動化余地`

### 避けたい言い方

- `問い合わせ全体を70%削減`
- `自治体全体で大幅削減`
- `どの自治体でも半分以上自動化`

## 住民課向けにそのまま使える文案

`住民課のマイナンバーカード関連のように、通知到着後の手順確認や持参物確認など、定型質問が集中する業務では、AIによる一次対応の自動化余地が大きいと考えています。実際の削減効果は自治体規模やFAQ整備状況によって変動するため、まずはPoCで効果を実測しながら展開する進め方を想定しています。`
