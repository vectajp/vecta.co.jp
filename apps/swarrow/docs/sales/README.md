# 営業資料メモ

現在の配布資料・商談資料は、Vectaリポジトリの [共通営業資料](../../../../docs/sales/README.md) に統一した。このディレクトリは旧HTML版の原稿・検討履歴として保持する。今後の機能説明、画像、導入事例の更新は共通版に行う。

営業資料づくりに使うメモをここにまとめる。

- `miyagawa/`
  - 宮川のプレゼン用のHTML営業スライド一式と関連メモ

運用メモ:

- 数字は `問い合わせ削減` `工数削減` `AI完結率` `待ち時間短縮` を分けて扱う
- 競合や公開事例の数字は、そのままSwarrowCallの実績として転用しない
- SwarrowCall向けには `PoCで実測する前提` の書き方を優先する
