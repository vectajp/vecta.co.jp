## 再生成

`update-deck.mjs` は前版r3のPowerPointを入力とし、7枚目の画像と配置を更新する。`@oai/artifact-tool` と既存のプレゼンテーション用ランタイムを使用する。`normalize-table-borders.py` は既存の罫線正規化処理。出力がある場合は版番号を更新する。
