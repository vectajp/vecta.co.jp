`update-deck.mjs` はローカルの `../20261027/output/pptx/Swarrow_商談用営業資料_20261027_r2.pptx` を入力とし、7枚目の画像・キャプション・発表者ノートのみ更新する。r2自体は既存の生成物であり、この改訂には再収録していない。`@oai/artifact-tool` とプレゼンテーション用の既存ランタイムが必要。出力が存在する場合は版番号を更新する。

`update-priced-brochure.py` は選択済みの軽量パンフレット2ページに、前版の料金別紙3ページ目を連結する。入力元とハッシュは `manifest.json` に保持した。パンフレット本体の編集ソースは同manifestの `brochure_source_directory` にある。
